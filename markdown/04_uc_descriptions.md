# Use Case Descriptions

## 팀원 1 담당 (UC01 · UC02 · UC03)

### UC01 – 회원가입

| | Actor Action | System Response |
|--|-------------|-----------------|
| | |1. 각 입력 텍스트 필드를 표시한다. |
| |2. 사용자가 ID를 입력한다. |3. 입력한 ID의 중복 여부를 표시한다. |
| |4. 사용자가 비밀번호를 입력한다. |5. 입력한 비밀번호의 보안 정책 충족 여부를 표시한다. |
| |6. 사용자가 이름과 전화번호를 입력한다.  |7. 없음 |
| |8. 사용자가 이메일을 입력한다. |9. 입력한 이메일의 중복 여부를 표시하고 모든 필드가 입력된경우 회원가입 버튼 활성화한다. |
| |10. 사용자가 회원가입 버튼을 누른다. |11. 회원가입 여부를 팝업으로 알려주고 로그인 화면으로 이동한다. |

**Extensions**

---

### UC02 – 회원 탈퇴

| | Actor Action | System Response |
|--|-------------|-----------------|
| | |1. 회원 탈퇴시 모든 데이터가 삭제됨을 고지하고 회원탈퇴 버튼을 활성화한다.
| |2. 사용자가 회원탈퇴 버튼을 누른다.  |3. 회원 탈퇴를 진행 후 팝업으로 회원탈퇴 성공 여부를 알려주고 성공시 로그인 페이지로 이동한다. |

**Extensions**

---

### UC03 – 로그인

| | Actor Action | System Response |
|--|-------------|-----------------|
| | |1. ID / PW 텍스트필드를 표시한다.  |
| |2. 사용자가 ID와 PW를 입력한다. |3. ID / PW 필드가 입력된 경우 하단의 로그인 버튼을 활성화 한다.  |
| |4. 사용자가 로그인 버튼을 누른다.  |5. ID / PW 검증 후 성공시 메인페이지 이동 / 실패시 로그인 실패 팝업을 생성한다. |

**Extensions**
