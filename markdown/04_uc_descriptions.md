## 팀원 4 담당 (UC10 · UC11 · UC12)

### UC10 – 응답한 설문 조회

| Actor Action | System Response |
|-------------|-----------------|
| | 1. 회원이 응답한 모든 설문에 대해 설문 제목, 응답 내용, 응답 일시 등이 출력된다. 현재 진행 중인 설문에 대해서는 수정 버튼이 활성화 되어 있다. |
| 2. 현재 진행 중인 설문에 수정을 원하면 수정버튼을 누른다. | |

**Extensions**

단계 1 이후, 회원은 현재 진행 중인 설문에 대해서는 취소 버튼을 눌러 취소할 수 있다.

### UC11 – "현재 진행 중인 설문"에 대한 응답 수정

| Actor Action | System Response |
|-------------|-----------------|
| | 1. 회원이 이전에 응답했던 내용과 가장 최근에 수정한 날짜가 출력된다. |
| 2. 설문 응답 내용을 수정합니다. | 3. 없음|
| 4.  수정하기 버튼을 누른다. | |

**Extensions**

### UC12 – 설문 응답 통계 정보 조회

| Actor Action | System Response |
|-------------|-----------------|
| | 1. 3개의 기간 선택 버튼(1주일, 1개월, 1년)을 표시한다. |
| 2. 관리자가 원하는 조회기간을 선택하여 해당하는 버튼을 누른다. | 3. 선택된 해당 기간의 통계 데이터( 기간 동안의 전체 설문 수 , 종료된 설문 수, 총 응답 수) 를 조회하여 표시한다. |

**Extensions**
