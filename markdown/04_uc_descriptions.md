## 팀원 3 담당 (UC07 · UC08 · UC09)

### UC07 – 설문 검색

| Actor Action | System Response |
|--------------|-----------------|
| | 1. 설문 진행 상태 선택 버튼과 검색어 입력을 위한 텍스트 필드를 표시한다. |
| 2. 회원은 설문 진행 상태(진행 중,진행 예정, 종료)중 하나를 선택하고, 키워드를 입력한 후 검색한다. | 3. 입력된 키워드와 설문 진행 상태의 조건에 맞는 설문 리스트를 출력한다. |

**Alternative Courses 없음**

### UC08 – 설문 상세 정보 조회

| Actor Action | System Response |
|--------------|-----------------|
| | 1. 회원이 선택한 설문의 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각 등이 출력 된다. 현재 진행 중인 설문인 경우에는 응답버튼이 활성화 되어있다. |
| 2. 현재 진행 중인 설문에 응답을 원하면 응답버튼을 누른다. | |

**Alternative Courses 없음**
