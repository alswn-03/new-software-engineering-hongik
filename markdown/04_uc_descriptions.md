### UC05 – 설문 등록

| Actor Action | System Response |
|-------------|-----------------|
| | 1. 각 입력 텍스트 필드를 표시한다. |
| 2. 관리자가 설문 제목을 입력한다.  | 3. 없음 |
| 4. 관리자가 설문 설명을 입력한다. | 5. 없음 |
| 6. 관리자가 설문 시작 시각, 마감 시각을 입력한다. | 7. 없음 |
| 8. 관리자가 설문의 첫번째 문항 내용과 답변을 작성한다.| 9. 모든 텍스트 필드가 입력된 경우 “등록하기”버튼 활성화한다. |
| 10. 관리자가 두개 이상의 문항이 필요한 경우 “문항 추가” 버튼을 눌러 문항을 추가한다.| 11. 문항 제목 텍스트필드와 3개의 답변 텍스트 필드를 생성 후 “등록하기”버튼 비활성화한다. |
| 12. 관리자가 추가된 문항내용과 답변 입력한다.| 13. 모든 텍스트 필드가 입력된 경우 “등록하기”버튼 활성화한다. |
| 14. 관리자가 등록을 위해 “등록하기”버튼을 누른다. | 15. 입력된 설문을 등록하고 성공 여부를 팝업으로 알려준다. |



**Extensions**

### UC06 – 설문 리스트 조회 / 삭제

| Actor Action | System Response |
|-------------|-----------------|
| | 1. 시스템은 관리자가 등록한 설문 목록을 조회하여 목록 형태로 표시한다.|

**Extensions**
#### 단계 1 이후, 관리자가 특정 설문을 삭제하기 위해 설문 목록에서 특정 설문 항목의 삭제 버튼을 눌러 삭제할 수 있다. 단계 1 이후, 관리자가 특정 설문의 상세 정보를 조회하기 위해 설문 목록에서 원하는  설문을 눌러 팝업 형태로 조회할 수 있다.

## 팀원 4 담당 (UC10 · UC11 · UC12)

### UC10 – 응답한 설문 조회

| Actor Action | System Response |
|-------------|-----------------|
| | 1. 회원이 응답한 모든 설문에 대해 설문 제목, 응답 내용, 응답 일시 등이 출력된다. 현재 진행 중인 설문에 대해서는 수정 버튼이 활성화 되어 있다. |
| 2. 현재 진행 중인 설문에 수정을 원하면 수정버튼을 누른다. | |
